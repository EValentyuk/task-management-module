# Модуль «Управление и планирование задач»

Постановка модуля для внутреннего приложения учёта задач компании «Умная Логистика». Задача модуля – добавить к личным задачам делегирование между сотрудниками: с явной моделью ответственности, приёмом и отклонением передачи.

## Ключевое решение

У задачи три роли: **Автор**, **Ответственный** и **Исполнитель**. Делегирование передаёт роль Исполнителя; Ответственный по умолчанию остаётся за делегирующим. Это разделяет «кто отвечает за результат» и «кто выполняет» – основной смысловой узел постановки.
